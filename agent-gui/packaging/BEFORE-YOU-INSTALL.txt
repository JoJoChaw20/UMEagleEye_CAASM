EagleEye Agent connects this computer to your organisation's EagleEye dashboard.
It finds the devices on your network and reports this computer's security settings
(firewall, antivirus, updates, encryption) so your IT team can keep them safe.

HAVE THESE READY
  Your IT administrator gives you three things from the dashboard's Agents page:
    1. API URL     (looks like https://.../api/v1)
    2. Agent ID    (a long code like 1a2b3c4d-....)
    3. API key     (shown only once; keep it private)
  You will paste them into the agent after the installation.

WHAT HAPPENS
  - The agent installs into Program Files and starts in the system tray
    (the blue eye icon next to the clock).
  - On first start it shows exactly what it collects. Personal data options
    are off unless you switch them on.
  - Recommended: let it start when you sign in, so it keeps reporting.

WHAT IT NEVER COLLECTS
  Files or documents, browsing history, passwords, keystrokes, screenshots,
  email or messages, location, or the contents of your network traffic.

Nmap and Npcap (free network tools) are not included. The agent offers to
download them from their official websites after installation.
