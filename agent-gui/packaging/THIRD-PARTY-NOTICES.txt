EagleEye Agent - third-party components
=======================================

The packaged agent includes the following open-source components. Their licence
texts are available at the links below; the corresponding source code is available
from each project and from the EagleEye repository (agent-gui/).

Included in this package
------------------------
Python 3.12+ runtime            PSF License                   https://docs.python.org/3/license.html
PySide6 / Qt 6 (Qt for Python)  LGPL-3.0                      https://www.qt.io/licensing/open-source-lgpl-obligations
    Qt libraries are shipped as separate DLLs in this folder and may be replaced
    with compatible versions (LGPL-3.0 section 4).
keyring, pywin32-ctypes         MIT / BSD-3-Clause            https://github.com/jaraco/keyring
truststore                      MIT                           https://github.com/sethmlarson/truststore
pysnmp, pyasn1                  BSD-2-Clause                  https://github.com/lextudio/pysnmp
Chakra Petch (font)             SIL Open Font License 1.1     https://github.com/m4rc1e/Chakra-Petch
Geist, Geist Mono (fonts)       SIL Open Font License 1.1     https://github.com/vercel/geist-font
    Static instances of the fonts, renamed only in their name tables; the licence
    texts are in _internal\eagleeye\gui\assets\fonts.
Lucide icons                    ISC                           https://lucide.dev/license
IEEE OUI registry (MAC vendors) public registry data          https://standards-oui.ieee.org

PySide6 / Qt are used under the LGPL-3.0. Packet capture and decoding are the agent's
own code (Microsoft's built-in NDIS capture driver on Windows); no packet-capture library
is included.

NOT included (downloaded from the official site only if you ask for it)

nmap.org and npcap.com and opens them; you accept their licences in their installers.
